# LEXMORA Food — Frontend Demo

نسخة واجهات مستقلة تعمل بـ HTML وCSS وJavaScript فقط، دون Laravel أو قاعدة بيانات أو Backend.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل مجلد المشروع عبر Live Server.

## اللغات والمظهر
- العربية والإنجليزية عبر زر `ع/EN`، مع حفظ اللغة المختارة بين الصفحات.
- اتجاه RTL للعربية وLTR للإنجليزية.
- اختيار اللغة والمظهر من صفحة الإعدادات.
- السلة والبيانات التجريبية تحفظ محلياً في `localStorage` على نفس المتصفح.

## الصفحات
الرئيسية، القائمة، من نحن، اتصل بنا، تسجيل الدخول، إنشاء حساب، لوحة العميل، السلة، إتمام الطلب، الرسائل، والإعدادات.

## حدود النسخة
هذه نسخة عرض Frontend Demo؛ لا يوجد تسجيل دخول حقيقي أو إرسال رسائل أو دفع أو حفظ طلبات على خادم. جميع العمليات محلية وتجريبية.
